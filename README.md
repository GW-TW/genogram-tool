# 家系圖工具

給社工用的家系圖與生態圖編輯器。整個工具就是一個 HTML 檔，用瀏覽器開啟就能用，完全離線，資料不會離開你的電腦。

作者：王錫凡（GW-TW）｜聯絡：amber31345@gmail.com｜**僅限公益用途，不開放商業使用**（見下方「授權」）

## 怎麼用

1. 下載 [`dist/家系圖工具.html`](dist/家系圖工具.html)，存到自己的電腦。
2. 雙擊用 Edge 或 Chrome 開啟。
3. 工具右上角的「使用說明」有完整的操作說明，以及每個符號、每種線條代表什麼；旁邊的「作者：王錫凡」是作者資訊（版本、授權、聯絡方式與 CRPD 宣言）。

## 可以畫什麼

- **家系圖**：男、女、未知性別、寵物；伴侶關係 20 種（結婚、分居、離婚、同居、婚約、交往⋯⋯）；
  親生、收養、寄養子女；雙胞胎；情感關係 36 種（親近、疏離、衝突、暴力、虐待、控制⋯⋯）；生活圈（同住）；文字說明。
- **人物資料**：年齡、職業、經濟等欄位會自動顯示在圖上；人物狀態（懷孕、流產、墮胎、移民、疾病與成癮）照符號慣例畫在符號上。
- **生態圖**：資源（學校、醫院、社福中心⋯⋯）與生態連結（強弱、壓力、資源流向、線上寫一件事），
  可以切換「只看家系圖／家系圖＋生態圖／生態圖（家庭收成一個圓）」。
- **圖形化操作**：拖曳人物、資源與生態圖的「家庭」圓；把人拖進生活圈的虛線圈就能加入。
- **自動排版**（選用）：再婚、多段婚姻、兩邊的原生家庭排不好時，按一下依世代重新排列；不滿意可以復原。
- **存檔與匯出**：存成 `.json` 檔，之後可以再開啟修改；匯出 PNG、SVG，或「複製圖片」直接貼進 Word。

符號與線條依常用的家系圖符號慣例（參考 GenoPro 的符號表）繪製。

## 隱私

- 不連網路：頁面的安全政策（CSP）禁止任何網路連線，也沒有載入任何外部資源。
- 不使用瀏覽器的儲存空間；資料只存在你自己選擇存檔的位置。
- 預設檔名是「個案編號_家系生態圖_建立日期」，不會帶入人名。

## 開發

- 原始碼在 `src/`，`python tools/build.py` 會打包成單一檔案 `dist/家系圖工具.html`。
- `python tools/test.py` 用 Edge（沒有的話用 Chrome）的無頭模式跑單元測試，再對打包好的檔案做開機自我測試。
- Windows 主控台請先設定 `PYTHONIOENCODING=utf-8`。
- 不需要 Node.js，也沒有任何第三方程式套件。介面樣式來自作者自訂的設計系統；色彩變數的命名沿用 open-design 的共用慣例（Apache License 2.0）。
